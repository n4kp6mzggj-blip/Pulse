# Pulse — Mac 系统监控面板

原生 SwiftUI / AppKit 应用，面向日常查看。所有指标在本机采集，无账号、无联网服务、无第三方运行依赖。

## 使用

打开随附的 **Pulse.app** 即可。菜单栏会显示 CPU 占用，点击可打开简洁面板；主窗口展示完整仪表盘。关闭主窗口后可从菜单栏重新打开，使用菜单栏的“退出 Pulse”或 ⌘Q 完全退出。

这是本机编译、临时签名的开发版本，尚未经过 Apple 公证。当前交付的二进制为 Apple Silicon 版本。源代码要求 macOS 14+，使用 Swift 5.9+ 和 Xcode Command Line Tools 编译；Intel 版本需要在对应架构上构建并验证。

## 已实现

- 总览：CPU、内存、网络、启动磁盘、资源排行、电源和热状态。
- CPU：全机和每逻辑核心的实际负载，使用 Mach 计数器差值。
- 内存：已用、总量、固定、压缩、文件缓存、交换空间和系统压力。
- 网络：所有 `en*` 物理接口的上传/下载速率，主接口 IPv4、启动后累计流量。
- 存储：APFS 启动数据卷容量和可用空间，每 15 秒刷新。
- 进程：可访问进程的驻留内存排行，可切换 CPU 排行，每 8 秒更新。CPU 单核满载为 100%，未合并辅助进程；CPU 排行需要至少两次采样。
- 电源：内置电池电量、充电状态、系统提供的估计时间。无电池机型会显示外接电源。
- 最近 15 分钟的内存内历史，1 / 5 / 15 分钟图表范围，CSV 导出。
- 1 / 2 / 5 秒采集间隔、暂停/继续、菜单栏快捷面板。

| 暂停 / 继续 | ⌘⇧P |

## 构建与诊断

```sh
chmod +x build.sh
./build.sh
./dist/Pulse.app/Contents/MacOS/Pulse --diagnose
```

诊断会间隔约 1 秒读取两次真实指标，验证 CPU 和内存范围、磁盘容量关系、网络速率以及可访问进程。还会短暂运行一个单核负载进程，验证进程 CPU 的时间单位和比例，随后自动结束该进程。失败时退出码为 1。

## 指标口径与限制

- 原生代码参考并改编了 MIT 开源项目 Stats 的 CPU / 内存采集思路与计算逻辑，见 `THIRD_PARTY_NOTICES.md`。本项目是独立面板，未 fork 整个 Stats 应用，也不是 iStatistica 官方版本。
- 内存已用量扣除可回收缓存，驻留内存不等于活动监视器的应用内存口径。
- 网络总速率汇总所有启用的 `en*` 接口，不重复统计 VPN 虚拟接口；仅有其他类型接口的环境不在当前范围内。接口内部转发也可能计入。接口重置时可能影响首个样本。
- 暂停会停止采集。恢复后的第一帧 CPU / 网络速率反映暂停期间平均值，网络累计也会包括暂停期间流量。
- 图表按真实采样时间显示；刚启动时从右侧开始积累，不填造历史。历史只存在进程内存中，退出清空。CSV 的 CPU 和电池按百分比、内存按字节、速率按字节/秒导出；空值表示不可用。
- 存储显示 `/System/Volumes/Data`，APFS 快照、容器共享及可清理空间可能导致与 Finder 有差异。
- 热状态是系统报告的 nominal / fair / serious / critical 等级，**不是摄氏温度**。
- 温度传感器、风扇转速/控制、GPU、外置磁盘、开机启动、通知和长期历史尚未实现。
- 当前优先验证本机 Apple Silicon，未承诺所有 Mac 的传感器或旧系统兼容性。

## 文件结构

- `Sources/Pulse/Metrics.swift`：后台采集与状态。
- `Sources/Pulse/Dashboard.swift`：总览、菜单导航、图表、偏好设置。
- `Sources/Pulse/DetailPage.swift`：各指标详情。
- `Sources/Pulse/PulseApp.swift`：应用入口、菜单栏、CSV 和诊断。
